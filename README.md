# Emotion Detection Web Application

## Project Description
A Python web application that detects emotions in customer feedback using the IBM Watson NLP Emotion Detection service.

## Features
- Detects anger, disgust, fear, joy, and sadness.
- Identifies the dominant emotion.
- Provides a Flask web application.
- Handles empty input and analysis errors.
- Includes unit tests for emotion detection.

## Technologies
- Python
- IBM Watson NLP Emotion Detection
- Flask
- Requests
- Unittest
